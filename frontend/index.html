// FEATURES

What it does

Every PR gets an automated AI review — inline comments, security checks, and a summary. No manual effort required.

🔍

AI Code Review

Uses LLMs to analyze diffs and provide intelligent, context-aware feedback on every pull request.

🛡️

Security Scanner

Detects hardcoded secrets, SQL injection risks, XSS vulnerabilities, and other security patterns.

📏

Static Rules

Catches TODOs, print statements, bare excepts — configurable rule engine that runs before the AI layer.

💬

Inline Comments

Posts review comments directly on the changed lines in your PR, not just a wall of text.

🧠

5 LLM Providers

Choose from HuggingFace, Groq, Gemini, Cerebras, or OpenRouter — switch anytime.

⚡

Zero Config

Install the GitHub App, pick a provider, and you're live. Reviews start automatically on every PR.

// HOW IT WORKS

The Pipeline

1

GitHub Webhook Fires

When you open or update a PR, GitHub sends a webhook event to PR Guardian's backend.

2

Diff Parsed & Rules Run

The diff is parsed into individual changed lines. Static rules scan for common anti-patterns.

3

LLM Analyzes Changes

The changed code is sent to your chosen LLM provider for an intelligent code review.

4

Comments Posted to PR

Inline comments are posted directly on the affected lines, plus a summary comment on the PR.

❯_ API DOCS

API Reference

All available endpoints for the PR Guardian AI backend.

GET / Health check

Returns the server status.

GET /

Response:
{
  "status": "ok",
  "app": "PR Guardian AI"
}
GET /test-llm/{provider} Test single LLM

Test a specific LLM provider. Optional ?model= query parameter.

GET /test-llm/groq
GET /test-llm/gemini?model=gemini-2.0-flash

Providers: huggingface, groq, gemini, cerebras, openrouter

Response:
{
  "status": "ok",
  "provider": "groq",
  "model": "llama-3.3-70b-versatile",
  "response": "..."
}
GET /test-llm Test all LLMs

Tests all 5 providers and reports which are working.

GET /test-llm

Response:
{
  "summary": "3/5 providers working",
  "working": ["groq", "gemini", "cerebras"],
  "failed": ["huggingface", "openrouter"],
  "details": { ... }
}
POST /webhook GitHub webhook receiver

Receives GitHub webhook events. Handles ping, installation, and pull_request events.

POST /webhook

Headers:
  X-GitHub-Event: pull_request
  X-Hub-Signature-256: sha256=...

Body: GitHub webhook payload (JSON)

Triggers on: opened, synchronize, reopened
POST /installations/{id}/settings Save installation settings

Create or update installation configuration (repos, LLM provider, model).

POST /installations/12345/settings

Body:
{
  "userId": "octocat",
  "selectedRepos": [
    {"repoId": 1, "fullName": "octocat/hello-world"}
  ],
  "reviewer": {
    "provider": "groq",
    "model": "llama-3.3-70b-versatile"
  }
}
PUT /installations/{id}/settings Update settings

Partially update an existing installation's configuration.

PUT /installations/12345/settings

Body (partial update):
{
  "reviewer": {
    "provider": "gemini",
    "model": "gemini-2.0-flash"
  }
}
GET /installations/{id} Get installation details

Returns full installation configuration including repos and reviewer settings.

GET /installations/12345

Response:
{
  "installationId": 12345,
  "userId": "octocat",
  "selectedRepos": [...],
  "reviewer": { "provider": "groq", "model": "..." },
  "createdAt": "2025-...",
  "updatedAt": "2025-..."
}
GET /users/{user_id}/installations List user installations

Returns all installations for a given GitHub user.

GET /users/octocat/installations

Response: Array of installation objects
GET /api/repos/{installation_id} List accessible repos

Returns all repositories accessible to a given installation.

GET /api/repos/12345

Response:
{
  "total_count": 5,
  "repositories": [
    { "id": 1, "full_name": "user/repo", ... }
  ]
}
GET /installations/{id}/info Get GitHub username

Returns the GitHub username (login) associated with an installation.

GET /installations/12345/info

Response: "octocat"

🔒 Privacy Policy

Last updated: 2025-11-21

1. Information We Do Not Collect

PR Guardian AI does NOT collect, store, or sell any personal information.

  • We do not store your name, email, or account information
  • We do not save repository contents
  • We do not log code or files outside GitHub
  • We do not track usage behavior or use cookies

2. Information the App Temporarily Processes

To perform reviews, PR Guardian AI temporarily receives:

  • Pull request event payloads
  • Code diffs provided by GitHub
  • Repository metadata (name, branches, PR ID)

This data is processed only in memory, never saved, and deleted immediately after the response.

3. Use of LLM APIs

Code diffs are temporarily sent to the configured LLM provider for review generation. Providers include HuggingFace, Groq, Gemini, Cerebras, and OpenRouter.

4. Security

  • All GitHub requests use authenticated installation tokens
  • Webhook signatures are validated
  • Private keys remain on the server
  • No data is stored or logged externally

5. Your Control

You may uninstall the app, revoke access, or remove installation permissions at any time. The app stops receiving data immediately.
